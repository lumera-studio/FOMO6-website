# FOMO6 Website

Static prelaunch preview for fomo6.fun. No wallet connection, RPC calls, or live jackpot; participation is disabled.

## Cloudflare Pages

Connect this repository, deploy branch `main`, choose framework None, no build command, and output directory `/` (repository root). No secrets or environment variables are needed.

Push changes to main to update the site automatically. Keep the existing site online until the Git-connected deployment is verified and the custom domain is migrated.

The contracts are maintained separately at https://github.com/lumera-studio/FOMO6. This preview does not represent a deployed game.
